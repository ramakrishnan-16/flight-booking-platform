---------------------------------------------------------
ABOUT THE PROJECT
---------------------------------------------------------

The Flight Booking Platform is an end-to-end full-stack
flight reservation and management system designed to
provide users with a complete flight search and booking
experience.

The platform allows users to search and filter flights,
check availability, view flight details, manage passengers,
make bookings, save flights, and select payment options.

The system provides secure JWT authentication and
role-based access control with separate user and
administrator workflows. Administrators can manage
flights, bookings, users, schedules, and seat availability.

The platform supports flight data from multiple sources,
including external flight APIs and uploaded CSV, Excel,
PDF, DOCX, JSON, and text documents.

A FastAPI-based AI assistance service helps users with
flight search and booking-related queries and assists
administrators in extracting, processing, validating,
and importing flight information from uploaded documents.

HOW THE SYSTEM WORKS
---------------------------------------------------------

* Flight data is collected from external APIs
* Administrators can upload flight documents
* Documents are processed by the AI assistance service
* Flight information is extracted from documents
* Extracted data is structured and validated
* Valid flight data is imported into MongoDB
* Users search for available flights
* Users filter flights based on their requirements
* Users view detailed flight information
* Users manage passenger information
* Users create flight bookings
* Users select available payment options
* Seat availability is updated during booking
* Administrators manage flights and bookings
* Expired flights are automatically managed
